Titre: Modèle de PR pour Design

Résumé des changements
- Décrire brièvement la nouvelle direction visuelle et les composants touchés.

Checklist (à cocher avant de demander review)
- [ ] Assets ajoutés dans `design/assets/` ou `frontend/src/assets/design/`
- [ ] `design/spec.md` incluant couleurs et polices
- [ ] Captures d'écran avant / après dans la description de la PR
- [ ] Lien Figma fourni (si applicable)
- [ ] Tests visuels réalisés (desktop / mobile)
- [ ] Note d'accessibilité (contrastes vérifiés)

Notes pour le reviewer
- Indiquer le contexte d'utilisation des nouveaux tokens.
- Lister les fichiers modifiés côté CSS/Token (ex: `src/index.css`, `tailwind.config.js`).
